# Pinautos - Centro Especializado Automotriz 🚗🔧

Sitio web oficial y sistema de gestión para **Pinautos**, un centro especializado de servicio automotriz ubicado en **Sogamoso, Boyacá**. La plataforma permite a los usuarios conocer los servicios del taller, registrar y consultar sus vehículos, gestionar citas de mantenimiento, facturación, inventario, y obtener información detallada sobre cómo ubicar y contactar al centro de servicio.

---

## 🚀 Características Principales

* **Gestión de Usuarios y Vehículos:** Registro de clientes y control detallado del historial vehicular.
* **Módulos del Taller:** Control de inventario, facturación, mantenimiento y servicios autorizados.
* **Página Web Informativa:** Sección pública para clientes con información de contacto, horarios y geolocalización en Sogamoso.
* **Arquitectura Híbrida:** Backend robusto en Django y entorno de desarrollo frontend optimizado con Node.js.

---

## 🛠️ Tecnologías Utilizadas

* **Backend:** Python 3.11+ & Django Web Framework
* **Base de Datos:** SQLite 3 (Entorno de desarrollo)
* **Frontend & Herramientas:** Node.js, Bootstrap 5 (vía Django Crispy Forms)
* **Control de Versiones:** Git & GitHub
